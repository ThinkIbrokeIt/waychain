Social recovery via 3+ guardian approvals. This is a no-selector precompile (raw signed-input layout). Recovery is a write op requiring guardian signatures — gated behind a connected wallet.
If you lose access to your wallet, you can recover it using your guardians. This call requires the guardian signatures to be provided via the transaction data (see tx.js).
